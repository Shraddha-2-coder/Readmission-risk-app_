# Hospital 30-Day Readmission Risk Stratification

An industrial-style AI/ML project that estimates which diabetic patients are at higher risk of being readmitted to hospital within 30 days of discharge, so a care team can prioritise follow-up calls.

**Live app:** add your Streamlit link here

## Important: the data is synthetic
The dataset (`diabetic_data_synthetic.csv`) was generated by code to mimic the structure of the public UCI "Diabetes 130-US Hospitals (1999-2008)" dataset. It contains **no real patients**. Relationships such as the effect of weight on risk were built in by the author, so results show that the pipeline works, not clinical findings. This tool is for education and must not be used for medical decisions.

## What the project does
- Builds a 30-day readmission target (`readmitted == "<30"`)
- Cleans the data and keeps a cleaning log
- Splits train/validation/test by patient, to avoid leakage
- Compares a baseline rule, Logistic Regression and Random Forest
- Calibrates probabilities (isotonic) and picks a threshold that flags the top 20% of patients
- Explains the model (SHAP / permutation importance) and checks fairness by gender, race, age and insurance
- Serves the model in a Streamlit app

## App modes
1. **Single patient:** enter details and get a risk score and key reasons
2. **Upload a file:** score a CSV (up to 5,000 rows) and download a ranked follow-up queue
3. **What-if explorer:** educational mode only
